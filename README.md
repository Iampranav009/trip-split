# ✈️ Rupaya Split by Pranav Shinde

**Rupaya Split** (also known as **RupayaSplit**) is a high-performance, mobile-first web and native mobile application engineered for seamless group travel expense tracking, bill splitting, and automated debt settlement. 

Developed and engineered by **Pranav Shinde** as part of the **Pranav Shinde Portfolio** and **Migrator Projects**.

---

## 🌟 Key Features

- 💸 **Smart Bill Splitting**: Split group expenses equally, by percentages, or custom exact amounts.
- 🔄 **Optimal Debt Settlement**: Algorithmic debt simplification algorithm to minimize payment transactions between members.
- 📲 **Articulated WhatsApp & Native Link Sharing**: Share trip invitations with dynamic Open Graph cards and QR code scanners.
- 📄 **PDF Invoice Export**: Generate itemized PDF billing reports for reimbursement.
- 🔒 **Firebase Realtime Sync & Security**: Real-time multi-device cloud synchronization with user authentication.
- 🌐 **SEO Optimized**: Fully indexed for search engines with Schema.org JSON-LD structured data and social cards.

## 🛠️ Tech Stack

- **Frontend**: React 18, TypeScript, Tailwind CSS, Lucide Icons
- **Backend & Auth**: Firebase Firestore & Firebase Authentication
- **PDF Generation**: jsPDF & AutoTable
- **Mobile Support**: Capacitor JS (Android / iOS)
- **Asset Engine**: Vector SVG Favicon, 512px App Logo, Open Graph 1200x630 Social Cards
